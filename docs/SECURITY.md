## 🚨 Güvenlik Açığı Bildirimi

`parslinux-gnome-settings` paketinde veya ilişkili şablon betiklerinde potansiyel bir güvenlik açığı, yetki yükseltme (privilege escalation) riski ya da komut enjeksiyonu tespit ederseniz:

1. **Herkese Açık Issue Açmayın:** Güvenlik açığını GitHub Issues üzerinde herkese açık olarak paylaşmayınız.
2. **Doğrudan İletişime Geçin:** Açıklama, yeniden üretme adımları ve etki analizini içeren e-postanızı **[security@parslinux.org](mailto:security@parslinux.org)** veya **[dev@parslinux.org](mailto:dev@parslinux.org)** adresine iletiniz.
3. **Değerlendirme Süresi:** Ekibimiz bildirimi 48 saat içinde değerlendirecek ve gerekli güvenlik yamalarını hazırlayacaktır.
